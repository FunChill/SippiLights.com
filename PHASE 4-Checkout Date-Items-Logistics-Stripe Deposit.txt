## STRIPE (approved — standard stack)
- Add stripe + @stripe/stripe-js. Server side: Vercel serverless function /api/create-checkout-session (this repo deploys to Vercel — add /api directory).
- One-time payment Checkout Session for deposit amount. Metadata: booking_id.

- Booking row is created with status 'pending_deposit' BEFORE redirect to Stripe; availability engine already counts pending_deposit rows, preventing double-booking during payment.
- Abandoned sessions: Vercel cron or scheduled function releases pending_deposit bookings older than 60 minutes (set to 'cancelled').
- Success page /book/confirmed: confirmation summary + "what happens next." Cancel page returns to review step with order intact.
