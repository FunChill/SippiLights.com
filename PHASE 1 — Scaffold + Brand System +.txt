## CONTEXT
Sippi Lights is a marquee letter/number and event lighting rental business in Jackson, MS (39211). This is a full custom rebuild — a booking-machine website that handles intake, availability, scheduling, deposits, and FAQ so the owner rarely has to speak with clients. This phase builds the foundation: project scaffold, brand token system, approved hero section, navigation, and all 6 page shells with real copy.

## STACK (do not deviate)
- React 19 + TypeScript + Vite
- Tailwind v4
- Motion (framer-motion) for animation
- React Router for pages
- Deployment target: Vercel
- NO other dependencies without explicit approval

## BRAND SYSTEM — create src/styles/tokens.css and reference everywhere
- --charcoal: #1C1B19 (primary background)
- --charcoal-2: #242220 (raised surfaces)
- --warm-white: #FAFAF8 (primary text)
- --gold: #C9A84C (accent, CTAs)
- --gold-light: #E8D08A (hover states)
- --purple: #9B72CF (rare atmospheric accent only — glows, rim light)
- --text-muted: rgba(250,250,248,0.55)
- Headline font: Cormorant Garamond (Google Fonts) — weights 300, 400, 500 + italic
- Body/UI font: DM Sans (Google Fonts) — weights 400, 500
- Corners: 8px buttons, 12px cards
- Flat design. No decorative shadows. No gradient fills. Soft radial GLOW effects are permitted as atmosphere (they are light, not decoration — this is a lighting company).
