# Sippi Lights

Marquee letter/number and event lighting rental site for Sippi Lights (Jackson, MS).

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Motion (framer-motion) for animation
- React Router for pages
- Deployment target: Vercel

## Development

```bash
npm install
npm run dev
npm run build
```
